## Project 2:

### Project Overview

This R Shiny application was created to explore data from the ASA's Census@School project.

While the full dataset has more variables, I've selected about a half dozen that can be used to filter the data and then conduct some light EDA.
More information can be found on the ASA's website (link below) and you can take your students to the site to add their own responses to the survey.

#### Dataset Context

The data originates from an expansive student census profile documenting baseline metrics such as school transit times, preferred extra-curricular structures, digital usage baselines, and environmental profiles. Learn more at the Census at School - United States (https://ww2.amstat.org/censusatschool/).

#### Layout Inforamtion
*Sidebar Panel:* Use the checkboxes and sliders to select the subset of the data you want, then use the action button to update the request from the full dataset.
*Data Download Tab:* Download a filtered spreadsheet of the data you selected from the sidebar.
*Data Exploration Tab:* View some graphs, tables, and metrics on various combinations of variables you chose.
